# 快速开始指南

## Windows系统

### 步骤1: 创建虚拟环境

双击运行 `setup_venv.bat`，或在命令行中执行：

```cmd
setup_venv.bat
```

或者手动创建：

```cmd
python -m venv venv
```

### 步骤2: 激活虚拟环境

```cmd
venv\Scripts\activate
```

激活成功后，命令行前缀会显示 `(venv)`。

### 步骤3: 安装依赖

```cmd
pip install -r requirements.txt
```

### 步骤4: 启动服务

```cmd
python run.py
```

## Linux/Mac系统

### 步骤1: 创建虚拟环境

```bash
chmod +x setup_venv.sh
bash setup_venv.sh
```

或者手动创建：

```bash
python3.11 -m venv venv
```

### 步骤2: 激活虚拟环境

```bash
source venv/bin/activate
```

激活成功后，命令行前缀会显示 `(venv)`。

### 步骤3: 安装依赖

```bash
pip install -r requirements.txt
```

### 步骤4: 启动服务

```bash
python run.py
```

## 验证安装

启动成功后，访问以下地址：

- API文档: http://localhost:8000/docs
- 健康检查: http://localhost:8000/health

## 常见问题

### Q: Python版本不是3.11怎么办？

A: 可以指定Python版本创建虚拟环境：

**Windows:**
```cmd
py -3.11 -m venv venv
```

**Linux/Mac:**
```bash
python3.11 -m venv venv
```

### Q: 提示找不到python命令？

A: 
- Windows: 确保已安装Python并添加到PATH，或使用 `py` 命令
- Linux/Mac: 使用 `python3` 或 `python3.11`

### Q: 虚拟环境已激活但pip命令不可用？

A: 确保虚拟环境创建成功，尝试重新激活或重新创建虚拟环境。

## 退出虚拟环境

```bash
deactivate
```
