# 启动说明

## 快速开始

### 1. 创建虚拟环境（推荐）

**Windows:**
```bash
# 运行脚本创建虚拟环境
setup_venv.bat

# 激活虚拟环境
venv\Scripts\activate
# 或
activate_venv.bat
```

**Linux/Mac:**
```bash
# 运行脚本创建虚拟环境
chmod +x setup_venv.sh
bash setup_venv.sh

# 激活虚拟环境
source venv/bin/activate
# 或
source activate_venv.sh
```

**注意：** 如果不使用虚拟环境，确保系统Python版本为3.11+

### 2. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 3. 数据库配置

数据库配置已在 `config.py` 中设置：
- MySQL: 10.0.80.18:3307
- 数据库名: fae_tools
- Redis: 10.0.80.18:6379

### 4. 启动应用

```bash
python run.py
```

或者使用 uvicorn 直接启动：

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 5. 访问API

- API文档（Swagger）: http://localhost:8000/docs
- ReDoc文档: http://localhost:8000/redoc
- API根路径: http://localhost:8000/

## 首次运行

首次运行时会自动创建数据库表结构（`generate_schemas=True`）。

## 测试API

### 1. 注册用户

```bash
curl -X POST "http://localhost:8000/api/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "123456",
    "email": "admin@example.com",
    "nickname": "管理员"
  }'
```

### 2. 登录获取Token

```bash
curl -X POST "http://localhost:8000/api/auth/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=123456"
```

返回的 `access_token` 用于后续API请求。

### 3. 使用Token访问API

```bash
curl -X GET "http://localhost:8000/api/users/me" \
  -H "Authorization: Bearer <your_token>"
```

## 注意事项

1. **生产环境**：
   - 修改 `config.py` 中的 `SECRET_KEY`
   - 设置 `DEBUG=False`
   - 使用环境变量管理敏感配置

2. **数据库**：
   - 确保MySQL数据库已创建
   - 确保数据库用户有足够权限

3. **Redis**（可选）：
   - 当前未使用Redis，但已配置
   - 可用于缓存和会话管理

## 常见问题

### 1. 数据库连接失败

检查：
- MySQL服务是否启动
- 数据库连接信息是否正确
- 防火墙是否允许连接

### 2. 模块导入错误

确保：
- 已安装所有依赖
- 在项目根目录运行命令
- Python版本为3.11+

### 3. 端口被占用

修改 `run.py` 中的端口号，或使用：

```bash
uvicorn app.main:app --port 8001
```
